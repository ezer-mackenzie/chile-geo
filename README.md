# Chile Geo

Typed, dependency-light geographic visualization for Chile. The workspace includes an HTML Canvas renderer and an optional Three.js renderer backed by a bundled, simplified snapshot of official Biblioteca del Congreso Nacional (BCN) boundaries.

## Highlights

- All 16 Chilean regions, stored locally with four-decimal coordinate precision.
- Native Canvas 2D rendering with no runtime dependency.
- Three.js extrusion, lighting, orbit controls, and raycasting in the optional 3D entry point.
- Responsive rendering, click and hover callbacks, live metric updates, and explicit cleanup.
- ESM subpath exports for tree-shaking plus a UMD build.
- Strict TypeScript declarations generated by `vite-plugin-dts`.

## Packages

| Package | Purpose |
| --- | --- |
| `@chile-geo/maps` | Public 2D and 3D rendering APIs |
| `@geo-chile/data-geojson` | Existing processed GeoJSON datasets |
| `@geo-chile/data-topojson` | Existing processed TopoJSON datasets |

## Installation

```bash
bun add @chile-geo/maps
```

Install Three.js only when using the 3D renderer:

```bash
bun add three
```

## 2D quick start

```ts
import { Chile2DMap } from '@chile-geo/maps/2d';

const map = new Chile2DMap({
  container: document.querySelector<HTMLElement>('#map')!,
  defaultColor: '#cbd5e1',
  onRegionClick: (name, data) => console.log(name, data?.value),
});

map.updateData([
  { id: 'CL-RM', name: 'Santiago Metropolitan Region', value: 92 },
  { id: 'CL-VS', name: 'Valparaíso Region', value: 67, color: '#7c3aed' },
]);
```

The container must have a measurable size:

```css
#map { width: 100%; height: 640px; }
```

## 3D quick start

```ts
import { Chile3DMap } from '@chile-geo/maps/3d';

const map = new Chile3DMap({
  container: document.querySelector<HTMLElement>('#map')!,
  enableControls: true,
  maxExtrusionDepth: 4,
  onRegionHover: (name, data) => console.log(name, data),
});

map.updateData([
  { id: 'CL-AP', name: 'Arica and Parinacota Region', value: 12 },
  { id: 'CL-MA', name: 'Magallanes and Chilean Antarctica Region', value: 80 },
]);
```

Call `map.destroy()` before removing the owning view. It disconnects observers and events and disposes Canvas/WebGL resources.

## API

Both map classes implement `updateData(dataSeries: RegionData[]): void` and `destroy(): void`. `updateData` replaces the current metric snapshot without recreating the Canvas or WebGL context. Values are normalized against the largest positive value in the supplied series. Negative and non-finite values render at zero. A per-region `color` overrides the generated blue-to-red scale.

See the [API reference](docs/API.md), [data notes](docs/DATA.md), and package [README](packages/map-render/README.md).

## Development

Requirements: Bun 1.2 or newer and a browser with Canvas 2D; WebGL is required only for the 3D renderer.

```bash
bun install
bun run check
bun test
bun run build
```

Regenerate the embedded rendering asset with `bun run scripts/build-map-asset.ts`. To rebuild all source datasets from locally supplied BCN archives, run `bun run process-data`. This requires `unzip` and Mapshaper. No renderer performs network requests at runtime.

## Browser support

The library targets modern evergreen browsers with `ResizeObserver`, Pointer Events, Canvas 2D, and ES2022 modules. Consumers targeting older browsers should provide their own transpilation or polyfills.
